# Random Password Generator

## Project Description
A Python-based Random Password Generator that creates strong and secure passwords based on the user's selected preferences.

## Features
- Custom password length.
- Lowercase letters.
- Uppercase letters.
- Numbers.
- Special characters.
- Secure password generation using Python's `secrets` module.
- Option to generate multiple passwords.
- Input validation and error handling.

## Technologies Used
- Python
- Random
- Secrets
- String
